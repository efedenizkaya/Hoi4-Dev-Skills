# Claims register

Every hard behavioral claim in `skills/hoi4-modding/` carries a
`CLAIM(<id>)` marker and a row here. Sources: `game-doc` = a file in
`<game>/documentation/` (machine-generated by the game, version-stamped),
`game-file` = inspection of a vanilla game file, `log` = observed in the
game's own log output, `tool` = behavior of this repo's tools.
Game version for all rows: 1.19.4.1 unless noted.

**Unverified rows** are marked `**unverified**` in their Source column:
the claim is plausible community knowledge that has NOT been checked
against this game install yet. Treat them as leads, not facts — and send
a `game update`/verification PR if you can check one. Re-verify rows on every
game patch; delete rows that no longer hold.
