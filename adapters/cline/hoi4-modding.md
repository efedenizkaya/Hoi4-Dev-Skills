# HOI4 modding rules (Cline)

- Read `skills/hoi4-modding/SKILL.md` before any HOI4 modding task; follow
  its Working agreement and routing table.
- Review/explain requests authorize read-only investigation; enter the fix
  lane only when asked to change the mod.
- After any script change run: `python tools/validate.py <mod_dir>` from
  the repo root; fix new findings before reporting success.
- Game-behavior claims must be traceable to `docs/claims-register.md`;
  label anything unverified.
