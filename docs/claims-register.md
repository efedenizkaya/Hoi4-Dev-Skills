`CLAIM(<id>)` marker and a row here. Sources: `game-doc` = a file in
`<game>/documentation/` (machine-generated by the game, version-stamped),
`game-file` = inspection of a vanilla game file, `log` = observed in the
game's own log output, `tool` = behavior of this repo's tools.
Game version for all rows: 1.19.4.1 unless noted. Re-verify rows on every
game patch; delete rows that no longer hold.
