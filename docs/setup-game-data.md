# Setting up game-derived data

The skill's reference data is **not committed** — it is extracted from your
own game install, which makes it exact for the patch you actually play.

## What gets read

| Input | Where | Produces |
|---|---|---|
| Official docs | `<game>/documentation/*.md` — effects, triggers, modifiers, variables, script math, localisation objects; regenerated by the game each patch | `effects.json`, `triggers.json`, `modifiers.json` |
| Game version | `<game>/launcher-settings.json` (`rawVersion`) | version-stamped output folder |
| Base-game awareness (validator) | `<game>/localisation/english/*.yml`, `<game>/events/*.txt` | vanilla loc keys + vanilla event IDs |
| Error baseline (triage) | `%USERPROFILE%\Documents\Paradox Interactive\Hearts of Iron IV\logs\error.log` | classified/diffed errors |

On a default Steam install the game directory is
`C:\Program Files (x86)\Steam\steamapps\common\Hearts of Iron IV`.

## Run the extractor

```bash
python tools/extract.py                 # auto-detects the install
python tools/extract.py --game-dir "<path to Hearts of Iron IV>"
python tools/extract.py --out <dir> --summary-out <dir>/summary.json
```

Output lands in `extracted/<version>/` (git-ignored — nothing game-derived is
ever committed). A sanitized `summary.json` (version + counts only) is safe to
commit under `docs/data-summaries/`; reference data for released game versions
is tracked there as counts, not content.

If auto-detection fails, set the `HOI4_GAME_DIR` environment variable.

## Validate a mod

```bash
python tools/validate.py "<path to mod>"            # game auto-detected
python tools/validate.py "<path to mod>" --no-game  # offline, more false positives
```

## Triage error.log

1. Launch the game once **without** your change → save a copy of
   `logs/error.log` as baseline.
2. Launch with the change (Steam launch options: `-debug` enables extra
   debug logging and content).
3. Diff:

```bash
python tools/error_triage.py logs/error.log --against baseline.log
```

Negative deltas = fixed, positive = introduced. Only the deltas need your
attention.
